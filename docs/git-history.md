# Git History 증빙

Day 3 마감 때 아래 명령 결과를 그대로 붙여넣습니다. (담당: 대웅)

```bash
git checkout main
git pull origin main
git log --oneline --graph --all
```

## 결과

```txt
<!-- 여기에 붙여넣기 -->
```

## 확인 포인트
- 브랜치가 갈라졌다가 merge commit으로 합쳐지는 모양이 보이는지
- `Merge pull request #N from ...` 커밋이 팀원별로 남아 있는지
- 충돌 해결 머지 커밋이 보이는지
